## En qué trabajo

**Plataforma comercial de un fabricante de iluminación LED** · en producción desde 2026

Sistema completo de una empresa, construido y operado por mí: tienda mayorista y
minorista, CRM con embudo por etapas, cotizador, motor de prospección, agente de
WhatsApp con IA y panel de administración.

- 28 módulos de administración, 182 endpoints y 22 procesos automáticos diarios
- 3.625 empresas prospectadas de forma automática con puntaje de encaje
- Integración con Meta Marketing API y API de conversiones, con atribución del lado
  del servidor y 4.407 eventos de embudo registrados por canal
- PostgreSQL con seguridad por fila: los permisos viven en la base, no en el código

**Aplicaciones propias** · en producción

- Punto de venta multiempresa con aislamiento de datos por cliente, stock, compras y caja
- Sistema de turnos con agenda por profesional y recordatorios automáticos
- App de transporte urbano con arribos en vivo sobre la API municipal, con una capa
  de caché que resuelve el 96% de las consultas sin tocar el origen

**Sitios de clientes** · 6 en producción

Gastronomía, estética, indumentaria, fotografía y comercio minorista. Cada uno con
identidad visual propia, catálogo, reservas o carrito y medios de pago.
